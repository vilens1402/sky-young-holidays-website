# Sky Young Holidays

A responsive, Kumbh-inspired travel website for Sky Young Holidays, Nashik.

## Included
- Cinematic hero and branded introduction
- Nashik / Godavari heritage feature
- Domestic, international and custom holiday pathways
- About, WhatsApp enquiry, contact and map links
- Responsive mobile navigation, scroll reveals and reduced-motion support
- SEO description and social sharing metadata

## Run locally
Open `index.html` in a browser. No build step or package installation is required.

## Publish with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then Save.
4. Wait for GitHub Pages to publish the site. The published URL will appear in the Pages settings.

## Before launch
- Replace the editorial stock photography with licensed Sky Young Holidays photos.
- Add the official company logo (the current header uses a typographic SY monogram).
- Add verified package names, itineraries, prices, departure dates and inclusions. Package cards are intentionally not fabricated; ask customers to enquire for current availability.
- Confirm the Kumbh-related travel information and any event-specific details before publishing.
- Verify office hours and contact details.
